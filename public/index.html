数据保留与自动清理

每日备份完成后自动清理过期数据。备份默认保存在宿主机 /var/backups/gatekeeper。

后台登录账号

新密码不限制最短位数，留空表示只修改账号。保存后所有后台会话会退出，需要使用新凭据重新登录。

API 使用

客户端可上报当前出口 IP，服务端自动转换为网段

上报请求

curl -X POST https://你的域名/api/v1/whitelist \
  -H "Authorization: Bearer awl_你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"source":"server-01"}'

不传 ip 时自动使用请求的来源地址。指定地址时传入 {"ip":"203.0.113.8"}。

每个用户的客户端 API 请求间隔可在“系统设置”页面修改，超限返回 HTTP 429。

查询当前 Key 的网段

curl https://你的域名/api/v1/whitelist \
  -H "X-API-Key: awl_你的密钥"
